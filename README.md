### ~\*~\*~ ♫ &nbsp;&nbsp;&nbsp; *queueify* &nbsp;&nbsp;&nbsp; ♫ ~\*~\*~

An application that handles Spotify song queuing for your Twitch stream, with an OBS overlay widget, a setup dashboard, and a visual theme editor! <br />Disclaimer: clanker helped me, yippie!
